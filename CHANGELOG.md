# Changelog

## 0.1.0

- Initial self-hostable Remote MCP server.
- Added Supabase/PostgreSQL memory storage.
- Added Streamable HTTP `/mcp` endpoint.
- Added bearer token authentication.
- Added CRUD and export memory tools.
- Added artifact metadata, chunk recall, local storage, and S3-compatible storage adapters.
- Added artifact REST API endpoints.
- Added Docker, Render, Railway, Fly.io, VPS, and Claude setup documentation.
