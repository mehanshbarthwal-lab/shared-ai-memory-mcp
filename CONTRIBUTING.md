# Contributing

Thanks for helping improve Shared AI Memory MCP.

## Development

```bash
npm install
npm run build
npm run dev
```

Use TypeScript strict mode and keep changes modular. Memory search is intentionally simple in v1, but new search implementations should preserve the tool contracts.

## Pull Requests

- Keep PRs focused.
- Add or update docs for behavior changes.
- Run `npm run build` before opening a PR.
- Do not include real secrets, personal account names, private URLs, or deployment credentials.

## Security

Do not open public issues for vulnerabilities. See `SECURITY.md`.
